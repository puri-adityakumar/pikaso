# bob_sessions/ — Bob usage evidence

Submission deliverable: screenshots of **Bob IDE task session consumption
summaries** for every task that contributed to Pikaso, from **each team
member**. PNG preferred. This folder is committed to the public repo.

## Capture protocol (10 seconds per task)

1. Bob IDE → chat → **Tasks** → open the task.
2. Select the **task header** → consumption summary appears.
3. Screenshot → save here as `pikaso_task<NN>_<short-desc>.png`.
4. Repeat per task, per team member (prefix with your name if multiple:
   `<member>_pikaso_task<NN>_…png`).
