The problem
Chat is a lossy channel for design.
01

Words lose intent

“Make the hero feel less cramped” forces the agent to guess which element, which direction, how far.

02

Screenshots are static

Figma links and PNGs can't be pointed at. Nobody can say “this exact button” inside a chat thread.

03

Feedback becomes threads

Every round of visual notes is another chat conversation the agent has to re-interpret from scratch.

Coding agents ship HTML in seconds — but design review still happens in prose.

02 / 07
How it works
Annotate. Apply. Resolved.

1Annotate

Click any element in the live mockup — a numbered pin anchors the comment to its CSS selector.

2Bob applies

Bob reads the annotations file, edits the mockup in one batch, and the board live-reloads — no refresh.

◎
0 open
every pin greyed out

3Resolved

Each applied comment flips to resolved; its pin greys out and the label count drops to zero.

03 / 07
Multi-agent orchestration
One council. One fix cycle.

Scout — runs once

Reads the codebase and writes context/design-system.md. Greenfield is a first-class report.

Art Director — the only voice

Briefs every frame, convenes the council, merges verdicts, and speaks to the human.

Builders — in parallel

One builder per frame, all sharing the same token contract so parallel frames look like one product.

Critics — one fix cycle

Rubric verdicts only: PASS or FIX: […]. No debates, no endless review loops.

Final state — frames/pikaso-landing/mockup.html
Guarded. Lock is blocked with a 409 while any annotation is still open — nothing ships half-reviewed.
Bob Shell, fired. Locking spawns agentCommand (bob --non-interactive) with the implementation prompt on stdin.
Evidence, not memory. Purpose, token contract and resolved history travel with the spec.

Why it's different
Selector-anchored. Protocol-first. Zero dependencies.
body > h1

Pins survive refactors

Comments anchor to stable CSS selectors, not pixel coordinates — resize, move, refactor, the note stays on the element.

AGENTS.md

Any agent can play

A universal apply-loop protocol, builder rules and a critic rubric ship with the board. Your harness just reads files.

node:http

Nothing to install

Pure Node built-ins. No database, no bundler, no account, no dependencies — one command and the board is running.
